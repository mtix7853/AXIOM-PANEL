# AXIOM Control Panel

A completely redesigned management panel with an editorial control-room aesthetic.

## Visual direction

- Graphite / near-black base
- Paper-white typography
- Acid-lime active states
- No RGB neon, no glassmorphism, and no glow-heavy cards
- Wide desktop navigation with compact mobile navigation
- Redesigned subscription portal using the same AXIOM visual language

## Functionality

The existing backend, authentication, VLESS/Trojan configuration flow, subscription endpoints, QR generation, notifications, Telegram settings, Railway volume helpers, statistics, and deployment files are preserved.

## Run locally

```bash
pip install -r requirements.txt
python main.py
```

Then open `http://127.0.0.1:8000`.

## Version

`4.0.0-axiom`
